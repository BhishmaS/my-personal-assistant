# Health integrations

- `whoop/` — the custom WHOOP skill (auto-synced from the workspace skill).
- `google-health-connect/` — snapshot of the built-in Google Health Connect
  skill (reference copy; ask for a refresh to re-sync).
- `quest-diagnostics/` — notes on the Quest Diagnostics MyQuest
  website-login integration (no code; credentials stay in the Secure Vault).
- `bodyspec/` — the custom BodySpec skill: reads DEXA scan data (body
  composition, visceral fat, bone density, RMR) via the BodySpec REST API
  with an OAuth connection.
